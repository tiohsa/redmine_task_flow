# 一括編集の画面と公開入口

## 操作契約

| 操作 | 観測結果 |
| --- | --- |
| ツールバーの「属性を一括変更」 | 編集可能かつノード 2 件以上で開ける。初期表示は選択 0 件、全項目「変更しない」 |
| 対象選択 | 名前と種別を示すラベル付きチェックボックスで個別に選択・解除する。同名の対象を識別でき、選択件数を表示する。消失した対象があれば理由を見せ、その選択を外せる |
| 属性指定 | トラッカー・優先度・担当者・対象バージョンの 4 項目。担当者と対象バージョンは明示解除を選べる。選択・トラッカーを変えるたびに候補と可否を更新し、無効になった指定は理由を表示して明示的な修正を待つ |
| 適用不可 | 件数上限、対象消失、無効な指定、ステータス非互換などを該当対象・項目とともに説明する。件数違反が重なっても対象・項目別の理由を表示し、直前の保存失敗より現在の判定理由を優先する。指定が無効になった項目も「変更しない」に戻せる |
| 適用 | 最新状態で全件を再判定する。成功でダイアログを閉じ、通常のノード表示に反映する。失敗で入力とダイアログを保持して再試行できる |
| 取消・Esc | 操作中の選択・指定を破棄する。適用前の取消や失敗ではノード・履歴・下書きを保持する |
| キーボード | 起動、対象と属性の指定、適用、取消を標準コントロールで操作できる。Shift+Tab でキャンバスから戻れるようにし、ツールバーにフォーカスがある間は標準のキー操作を優先する。開いている間はキャンバス操作を抑止し、Esc でダイアログを閉じても全画面表示は維持する。閉じた後は起動ボタンへフォーカスを戻す |

## 公開入口

- `frontend/src/features/bulk-node-edit/index.ts` が候補と適用案を返す純粋な評価関数、要求・結果の型を公開する。入力は既存のノードと Bootstrap メタデータ、および一括編集要求。候補、適用可否、該当する理由を同じ判定から返す。
- `useFlowStore.applyBulkNodeEdit` は選択 ID と指定値だけを受け取り、現在の可否、ノード、Bootstrap を使って評価する。保存成功時は履歴 1 件分の変更を確定する。プレビューの計算結果は適用入力に使わない。
- React はネイティブ `<dialog>` を ref から開く。ネイティブの close イベントと React の開閉状態を同期させる。対象群は `fieldset` / `legend`、操作はラベル付きの標準フォーム要素を用いる。件数と動的エラーは支援技術にも伝える。CSS は `.task-flow-root` 内に適用する。
